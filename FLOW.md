# IP 流量流程

## 1. LAN 客户端访问国内 (baidu.com)

```
                    192.168.100.x:45678 → baidu.com
                                  │
                    ① DNS 查询    │
                    ┌─────────────┘
                    ▼
            dnsmasq (192.168.100.1:53)
              │
              │ 匹配 accelerated-domains.china.conf
              │ server=/baidu.com/114.114.114.114
              │
              ▼
         114.114.114.114:53
              │
              │ 返回真实 IP: 111.63.65.247
              ▼
         192.168.100.x 收到 111.63.65.247
                                  │
                    ② TCP 连接    │
            src: 192.168.100.x:45678
            dst: 111.63.65.247:443
                                  │
                    ┌─────────────┘
                    ▼
            ┌───────────────┐
            │  enp2s0 入站   │
            └───────┬───────┘
                    │
                    ▼
            ┌─────────────────┐
            │ PREROUTING mangle│
            │                 │
            │ -d 198.18/16 ?  │  ✗ (111.63 ≠ 198.18)
            │ -d 192.168/16 ? │  ✗
            │ -d 10/8 ?       │  ✗
            │ -d 172.16/12 ?  │  ✗
            │                 │
            │ !china_ipv4？   │  ✗ 111.63.x.x ∈ china → 不打标
            └────────┬────────┘
                     │
                     ▼  mark: 无
            ┌─────────────────┐
            │    路由 (main)   │
            │                 │
            │ default via      │
            │ 10.202.47.254    │  metric 1002 ← 选中 ✓
            │ dev enp1s0       │
            │                 │
            │ default via      │
            │ 192.168.161.115  │  metric 1005 ✗
            │ dev usb0         │
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │  FORWARD        │
            │  enp2s0→enp1s0  │  ACCEPT
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │ POSTROUTING NAT  │
            │                 │
            │ -s 192.168/24   │
            │ -o enp1s0       │  MASQUERADE
            │                 │
            │ src: .100.x →   │
            │      10.202.34.189│
            └────────┬────────┘
                     │
                     ▼
            ┌───────────────┐
            │  enp1s0 出站   │
            └───────┬───────┘
                    │
                    ▼
         校园网 NAT: 10.202.34.189 → 183.95.255.73 (公网)
                    │
                    ▼
              baidu.com 服务器
```

**关键**: DNS 返回真实 IP → IP 在国内集合 → PREROUTING 不打标 → 主路由表 → enp1s0 校园网。

## 2. LAN 客户端访问国外 (google.com)

```
                    192.168.100.x:45679 → google.com
                                  │
                    ① DNS 查询    │
                    ┌─────────────┘
                    ▼
            dnsmasq (192.168.100.1:53)
              │
              │ 查 accelerated-domains.china.conf
              │ google.com 未匹配
              │
              │ 走默认: server=127.0.0.1#1053
              │
              ▼
         mihomo DNS (127.0.0.1:1053)
              │
              │ fake-IP 模式
              │ 返回 198.18.0.100
              ▼
         192.168.100.x 收到 198.18.0.100
                                  │
                    ② TCP 连接    │
            src: 192.168.100.x:45679
            dst: 198.18.0.100:443
                                  │
                    ┌─────────────┘
                    ▼
            ┌───────────────┐
            │  enp2s0 入站   │
            └───────┬───────┘
                    │
                    ▼
            ┌─────────────────┐
            │ PREROUTING mangle│
            │                 │
            │ -d 198.18/16 ?  │  ✓ 匹配 → RETURN (不打标)
            └────────┬────────┘
                     │
                     ▼  mark: 无
            ┌─────────────────┐
            │    路由 (main)   │
            │                 │
            │ 198.18.0.0/16   │
            │ dev utun        │  命中 → utun (mihomo TUN)
            └────────┬────────┘
                     │
                     ▼
            ┌───────────────────────────────┐
            │     mihomo TUN (utun)          │
            │                                │
            │  接收 198.18.0.100 → google.com│
            │  (fake-IP 映射 / TLS SNI 嗅探) │
            │                                │
            │  规则匹配:                      │
            │    GEOSITE,cn   → 不匹配        │
            │    GEOIP,CN     → 不匹配        │
            │    MATCH        → Auto (代理)   │
            │                                │
            │  连接代理节点:                   │
            │    103.181.165.104:16622       │
            └──────────────┬────────────────┘
                           │
                    ③ mihomo 出站
            src: 10.202.34.189 (enp1s0 IP)
            dst: 103.181.165.104:16622
            uid: 999 (mihomo)
                           │
                    ┌──────┘
                    ▼
            ┌─────────────────┐
            │  OUTPUT mangle   │
            │                 │
            │ uid=mihomo ?    │  ✓ → MARK 0x100 → RETURN
            └────────┬────────┘
                     │
                     ▼  mark: 0x100
            ┌─────────────────┐
            │ ip rule: 200     │
            │ fwmark 0x100     │
            │ → table 200      │
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │   table 200      │
            │                 │
            │ default via      │
            │ 192.168.161.115  │  → usb0
            │ dev usb0         │
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │ POSTROUTING NAT  │
            │                 │
            │ -o usb0         │  MASQUERADE
            │                 │
            │ src →           │
            │  192.168.161.30 │
            └────────┬────────┘
                     │
                     ▼
            ┌───────────────┐
            │  usb0 出站     │
            └───────┬───────┘
                    │
                    ▼
         手机 NAT: 192.168.161.30 → 183.95.251.79 (联通公网)
                    │
                    ▼
         代理节点 103.181.165.104:16622
                    │
                    ▼  (加密隧道)
              google.com 服务器
```

**关键**: DNS 返回 fake-IP → PREROUTING RETURN → 主表 198.18/16 → utun TUN → mihomo 匹配规则 → 代理节点 → OUTPUT 打标 0x100 → table 200 → usb0 手机。

## 3. 路由器自身访问国内

```
    curl myip.ipip.net (UID 1000)
              │
        ① /etc/resolv.conf
    nameserver 202.103.44.150  (首选)
    nameserver 114.114.114.114
    nameserver 127.0.0.1      (最后)
              │
    DNS 查询 → 202.103.44.150 → 真实 IP: 220.185.184.53
              │
        ② TCP: 220.185.184.53:80
              │
              ▼
    ┌─────────────────┐
    │  OUTPUT mangle   │
    │                 │
    │ uid=mihomo?     │  ✗ (UID 1000)
    │ !china_ipv4?    │  ✗ 220.x ∈ china → 不打标
    └────────┬────────┘
             │  mark: 无
             ▼
    ┌─────────────────┐
    │  路由 (main)     │
    │ 220.185.184.53   │
    │ via 10.202.47.254│  → enp1s0 (metric 1002)
    │ dev enp1s0       │
    └────────┬────────┘
             │
             ▼
    enp1s0 → 校园网 NAT → 183.95.255.73
```

## 4. 路由器自身访问国外

```
    curl ip.sb (UID 1000)
              │
        ① /etc/resolv.conf
    DNS 查询 → 202.103.44.150 → 真实 IP 或 IPv6
              │
        ② TCP: 非中国 IP
              │
              ▼
    ┌─────────────────┐
    │  OUTPUT mangle   │
    │                 │
    │ uid=mihomo?     │  ✗
    │ !china_ipv4?    │  ✓ 非中国 IP → MARK 0x1
    └────────┬────────┘
             │  mark: 0x1
             ▼
    ┌─────────────────┐
    │ ip rule: 100     │
    │ fwmark 0x1       │
    │ → table 100      │
    └────────┬────────┘
             │
             ▼
    ┌─────────────────┐
    │   table 100      │
    │ default dev utun │  → utun (mihomo TUN)
    └────────┬────────┘
             │
             ▼
    mihomo TUN 接收 → MATCH,Auto → 代理节点
             │
             ▼
    mihomo 出站: 0x100 → table 200 → usb0 → 手机 → 代理
```
